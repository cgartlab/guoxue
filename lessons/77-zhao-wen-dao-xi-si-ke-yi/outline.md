# 第 77 课 · 朝闻道，夕死可矣

《论语·里仁》第八章（全篇 26 章）

## 原文

> 子曰：“朝闻道，夕死可矣。”

### 字词疏解

| 字 | 音 | 释义 |
|---|---|---|
| 朝 | zhāo | 早晨。不读 cháo（朝廷、朝代）。“朝”“夕”相对，把时间缩到最短 |
| 闻 | wén | 听见 → 领会、真正懂得。不是“听说过”，是听进去了、心里明白了 |
| 道 | dào | 人生的正路、根本的道理。朱熹：“道者，事物当然之理。” |
| 夕 | xī | 傍晚、晚上。与“朝”相应，朝闻夕死说的是一天之内 |
| 死 | sǐ | 死去。不是叫人去死，是拿“死”当尺子，量“道”有多重 |
| 可 | kě | 值得、可以、没有遗憾。“可矣”＝行了、值了、这一生不亏了 |
| 矣 | yǐ | 句末语气词，表肯定、感叹，相当于“了”。说得斩钉截铁 |
| 朝闻夕死 | zhāo wén xī sǐ | 极言时间之短——哪怕只剩半天，明白了也值 |

### 译文

孔子说：“早上真正明白了道，即使晚上就死去，也可以没有遗憾了。”

## 核心思想

**八个字，说尽“道”的分量**

1. **闻道不是听说，是真明白** —— 听见、听懂、闻道，三层差着两层。听过千句，不如真懂一句。真明白了，行为一定跟着变；一点不变，就是还没真明白。
2. **道是安身立命的根本** —— 做人的正路、万事的道理、安心的地方。道不在天上，就在日常：怎么对父母、怎么对朋友、怎么对钱。
3. **明白，比活得久更要紧** —— “可矣”是“值了”，不是“该死了”。人怕死，多半是怕白活；知道了为什么活，寿长寿短就退到第二位。朱熹：“生顺死安，无复遗恨。”
4. **不怕晚，就怕不** —— “朝”“夕”不是催人，是给人留路。二十岁明白值，六十岁明白也值；怕的是一辈子没想过这回事。

## 生活应用

- **求学**：停在“听过”，等于没学。合上书，能不能用自己的话讲一遍？
- **立志**：先想明白为什么做。图明白了，苦也吃得下；图不明白，顺也走不远。
- **惜时**：明白不分早晚。别拿“我年纪大了”当推辞。
- **面对生死**：亲人离世、自己生病时，这句话给的不是安慰，是准头——守住了该守的，就不亏。

## 关联章句

- 《论语·里仁》“人之过也，各于其党。观过，斯知仁矣” —— 上一章（第七章，第 75 课）讲怎么看清人；本章讲为什么活。
- 《论语·里仁》“士志于道，而耻恶衣恶食者，未足与议也” —— 下一章（第九章）讲怎么守志：志在道，就不耻粗衣粗食。
- 《论语·卫灵公》“志士仁人，无求生以害仁，有杀身以成仁” —— 同一根，分寸不同：一个讲怎么守，一个讲值不值。
- 《论语·里仁》“富与贵，是人之所欲也……造次必于是，颠沛必于是” —— 第 74 课已讲：道在富贵贫贱上过秤。
- 《论语·先进》“未知生，焉知死” —— 孔子不谈死后，只问怎么活。本章正是“怎么活”的答案。
- 朱熹《集注》“道者，事物当然之理。苟得闻之，则生顺死安，无复遗恨矣” —— “生顺死安”四字最切。
- 《孟子·尽心上》“夭寿不贰，修身以俟之，所以立命也” —— 寿长寿短不动心，与本章同一路数。

## 十道测验

1. “朝闻道”的“朝”怎么读、什么意思？（zhāo，早晨 / cháo，朝代 / zhāo，朝拜）
2. “朝闻道”的“闻”最准确的意思是？（领会、真正懂得 / 耳朵听见 / 听说的传闻）
3. “夕死可矣”的“可”是什么意思？（值得、没有遗憾 / 可以允许 / 可能、也许）
4. “朝闻道，夕死可矣”是在叫人去死吗？（不是，是说闻道之可贵，死而无憾 / 是，叫人殉道 / 是，劝人看破生死）
5. 本章的“道”主要指什么？（做人的根本道理、人生正路 / 道路、路程 / 说话、说道）
6. 朱熹解释“夕死可矣”，用了哪四个字？（生顺死安，无复遗恨 / 杀身成仁，舍生取义 / 朝乾夕惕，不敢懈怠）
7. “朝”“夕”连用，想表达什么？（极言时间之短，明白无论早晚都值 / 真的只在一天之内 / 早晚都要做事，不可懈怠）
8. 本章在《里仁》篇中的位置是？（第八章 / 第六章 / 第七章）
9. 本章与《卫灵公》“杀身以成仁”是什么关系？（都把道看得比命重，但本章强调的是闻道之可贵 / 完全一样，都是叫人去死 / 意思相反，一个重道一个轻生）
10. 学过本章，最恰当的体会是？（先求明白，再问长短 / 人生苦短，及时行乐 / 道理听过一遍就够了）
