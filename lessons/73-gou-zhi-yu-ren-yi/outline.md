# 第 73 课 · 苟志于仁矣，无恶也

《论语·里仁》第四章（全篇 26 章）

## 原文

> 子曰："苟志于仁矣，无恶也。"

### 字词疏解

| 字 | 音 | 释义 |
|---|---|---|
| 苟 | gǒu | 诚、如果真的。朱熹："苟，诚也。"非"苟且""假如" |
| 志 | zhì | 心之所之，心所向往的方向。非"念头""记住" |
| 于 | yú | 介词，表归向："志于仁"即心之所向落在仁上 |
| 矣 | yǐ | 语气词，表确定、已然，相当于"了" |
| 无 | wú | 没有、不会。此处是"生不出来"，非"暂时没有" |
| 恶 | è | 恶事、做坏事。本章最易读错之字，另有一派读 wù |
| 志于仁 | zhì yú rén | 把心定在仁上，非"想做点好事" |
| 无恶也 | wú è yě | 不会去做恶事。非"没人厌恶他"，亦非"心里没有厌恶" |

### 译文

孔子说："一个人如果真的把心定在仁上，就不会去做恶事了。"

## 核心思想

**心有了主，恶就没了根**

1. **"苟"是"诚"** —— 不是假如，是当真。这一字是全章门槛：嘴上向善、心里算利的，不算志于仁。
2. **"志"是方向，不是念头** —— 念头管一阵子，志向管一辈子。心搬到仁上住，遇事不必每次重新商量。
3. **"无恶"不是硬忍，是生不出来** —— 孔子不说"不为恶"，说"无恶"：不为是压着不做，无是心里没长出来。
4. **仁是一盏灯，不是一道墙** —— 朱子："其心诚在于仁，则必无为恶之事矣。"灯亮着，脏东西自己躲开。
5. **立志是开头，不是毕业** —— 志要天天续：今天真，今天就无恶；明天松了，明天就难说。

## 生活应用

- **立志**：把"我不做什么"换成"我要做什么"，心里有正方向，歪的不易近身。
- **家教**：少列禁令，多养一颗心——常问"这样对人家公平吗"，而非只说"不许"。
- **做事**：先问"对不对"，再问"划不划算"，顺序一颠倒就给自己找理由。
- **自省**：睡前问一句"今天有没有为了自己方便，让别人吃了亏"，志不省就蒙尘。

## 关联章句

- 《论语·述而》"我欲仁，斯仁至矣" —— 仁非远物，真心要便到。
- 《论语·里仁》"君子无终食之间违仁，造次必于是，颠沛必于是" —— 志于仁者的日常功夫。
- 《论语·学而》"吾日三省吾身" —— 志须常省，不省则蒙尘。
- 朱熹《集注》"苟，诚也……其心诚在于仁，则必无为恶之事矣" —— 本章经典注脚。
- 本篇前三章：里仁为美（择处）→ 仁者安仁（守得住）→ 唯仁者能好人（待人有准）→ 本章（心里那个根）。
