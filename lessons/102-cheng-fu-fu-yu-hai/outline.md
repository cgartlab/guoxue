# 第 102 课 · 乘桴浮于海 · 好勇过我

《论语·公冶长》第七章

## 原文

> 子曰："道不行，乘桴浮于海。从我者，其由与？"子路闻之喜。子曰："由也好勇过我，无所取材。"

### 字词疏解

| 字 | 音 | 释义 |
|---|---|---|
| 桴 | fú | 木筏、竹筏。把木头或竹子编起来渡水 |
| 乘桴浮于海 | chéng fú fú yú hǎi | 坐木筏漂到海上去。"浮"字轻，其实无依无靠 |
| 道不行 | dào bù xíng | 我的主张行不通。不是说"路走不通" |
| 从 | cóng | 跟随 |
| 其……与 | qí……yú | 大概……吧。"与"同"欤"，表揣测，不是断言 |
| 闻之喜 | wén zhī xǐ | 听了很高兴。喜里还带着得意 |
| 好勇 | hào yǒng | 爱好勇武。"好"读 hào，爱好，不读 hǎo |
| 过 | guò | 超过。超过也就"过了"——勇过了头就是莽撞 |
| 材 | cái | 一说做木筏的木材；一说通"裁"，裁度、掂量。两说并存 |

### 译文

孔子说："我的主张行不通了，真想坐着木筏漂到海上去。能跟从我的人，大概只有仲由吧？"子路听了很欢喜。孔子说："仲由这个人，爱好勇武胜过我，可惜没处去取做木筏的材料啊。"

（"无所取材"另有两说：一说"材"通"裁"，指子路不能裁度事理；一说指"没有什么可取之处"。三说落点相同：勇气可嘉，分寸不足。）

## 核心思想

**最重的信重 · 常常长着拦阻的样子**

1. **"道不行"是一句伤心话，不是一份计划** —— 周游列国十几年，主张行不通，连孔子也动过远走的念头。
2. **"从我者其由与"是极重的认可，却说得极轻** —— 天下人都散了，能跟到底的只有一个；用"其……与"，是揣测，也是不自居。
3. **"闻之喜"是整章的转折** —— 同一句话，落进学生耳朵里长出了欢喜，落进老师心里长出了担忧。
4. **"好勇过我"是承认，"无所取材"是拦阻** —— 夸在前，点在后。这一盆冷水，是护他别把绝路当壮举。
5. **两个"喜"字，分出四种性情** —— 上一章漆雕开不肯轻应，老师"说"；这一章子路抢着要去，老师按住。

## 生活应用

- **听话**：听出话里的分量。别把一句感叹，当成一张请帖。
- **被看重**：别急着高兴，先弄清人家要你干什么、这一趟是什么路。
- **勇气**：勇要有，但不能只有勇。勇过了头，就是替自己找麻烦。
- **教孩子**：最疼的方式，有时是拦一下——点了你的名，不一定是让你去。

## 关联章句

- 《论语·公冶长》上一章"子使漆雕开仕……子说" —— 一个不肯轻应，老师喜；一个抢着要去，老师按住。
- 《论语·先进》"若由也，不得其死然" —— 孔子早知道这弟子会死于勇，知他才疼他。
- 《论语·述而》"暴虎冯河，死而无悔者，吾不与也" —— 徒手打虎、徒步过河，孔子不要这种人。
- 《论语·述而》"用之则行，舍之则藏" —— 孔子的常道；"乘桴浮于海"是撑不住时的一声叹。
- 《论语·微子》"鸟兽不可与同群" —— 他到底没有走。叹归叹，人还是留在人间。

## 十道测验

1. "乘桴浮于海"的"桴"是什么？（木筏、竹筏 / 船桨 / 大船）
2. "道不行"的"道"指什么？（道路 / 孔子的主张、治国之道 / 道理讲不通）
3. "从我者其由与"的"其……与"是什么语气？（肯定、断定 / 命令 / 揣测，大概……吧）
4. "由"指的是谁？（子路，姓仲名由 / 子贡 / 冉有）
5. "子路闻之喜"的"之"指代什么？（孔子说的那句话 / 海上的一座山 / 子路的勇名）
6. "好勇过我"的"好"读音和意思是？（hǎo，美好 / hào，爱好 / hào，容易）
7. "过"在这里是什么意思？（经过 / 超过 / 过错）
8. 子路为什么"闻之喜"？（因为老师要带他去打仗 / 因为他以为老师真要带他出海，觉得自己被看重 / 因为老师当场夸他勇敢）
9. 孔子说"由也好勇过我，无所取材"，主要用意是？（夸子路勇敢过人 / 责怪子路不听管教 / 提醒他光有勇气不够，也是护着他）
10. 本章在《公冶长》篇中是第几章？（第五章 / 第六章 / 第七章）
