# 第 71 课 · 仁者安仁，知者利仁

《论语·里仁》第二章（全篇 26 章）

## 原文

> 子曰："不仁者不可以久处约，不可以长处乐。仁者安仁，知者利仁。"

### 字词疏解

| 字 | 音 | 释义 |
|---|---|---|
| 不仁者 | bù rén zhě | 没有仁德的人 |
| 约 | yuē | 穷困、窘迫、俭约之境 |
| 处 | chǔ | 处于、安处、居 |
| 长 | cháng | 长久、长时间 |
| 乐 | lè | 安乐、富足顺遂之境 |
| 安仁 | ān rén | 以仁为安身之处，自然而然地安于仁 |
| 知 | zhì | 通"智"，明智、有见识 |
| 利仁 | lì rén | 见仁之利而实行仁，认为行仁对自己有益 |

### 译文

孔子说："没有仁德的人，不能长久地安处于穷困之中，也不能长久地安处于安乐之中。有仁德的人安于仁，明智的人知道仁对自己有利而力行仁。"

## 核心思想

**境遇是试金石 · 安仁与利仁**

1. **不仁者守不住穷** —— 久处困窘，便怨天尤人、投机取巧，甚至为非作歹。
2. **不仁者也守不住富** —— 久处安乐，便骄纵放肆、淫逸失度，富贵反而成了祸根。
3. **仁者安仁** —— 仁者的心安放在仁上，穷也不改，达也不改，不靠外境定心。
4. **知者利仁** —— 明智的人看清仁是安身立命最实在的好处，所以主动去行仁。
5. **境界有别** —— 安仁是"自然如此"，利仁是"明白如此"；一个从心上安，一个从理上入，最终都归于仁。

## 生活应用

- **穷时不失志**：手头紧、条件差的时候，最容易看出一个人的底子。
- **富时不失度**：成绩好、条件好的时候，最容易得意忘形。
- **交友**：只在顺境陪你笑的人，未必能在困境陪你走。
- **学习**：把学习当成"对我真有好处"的事（利仁），比靠一时热情更靠得住。

## 关联章句

- 《论语·里仁》"君子喻于义，小人喻于利" —— 义利之辨。
- 《论语·学而》"贫而无谄，富而无骄" / "贫而乐，富而好礼" —— 与本章互为表里。
- 《论语·卫灵公》"君子固穷，小人穷斯滥矣" —— 正是"不仁者不可以久处约"的注脚。
- 《论语·述而》"饭疏食饮水，曲肱而枕之，乐亦在其中矣" —— 孔子自道"久处约"的样子。

## 十道测验

1. 本章的说话人是谁？（孔子 / 有子 / 曾子）
2. "不可以久处约"的"约"是什么意思？（约束 / 穷困窘迫 / 约定）
3. "长处乐"的"乐"指的是什么？（音乐 / 快乐的心情 / 安乐富足的境遇）
4. "仁者安仁"的"安"应如何理解？（安全 / 以……为安身之处 / 安抚）
5. "知者利仁"的"知"通哪个字？（智 / 志 / 止）
6. "知者利仁"的"利"是什么意思？（利益集团 / 认为……有利而去做 / 锋利）
7. 孔子认为"不仁者"的两大问题是什么？（穷时守不住、达时也守不住 / 不会挣钱、不会花钱 / 不读书、不劳动）
8. "仁者安仁"与"知者利仁"的分别是？（前者更高一层，后者次一等 / 二者对立，不能并存 / 前者是自然安于仁，后者是明白仁的好处而行仁）
9. 与本章意思最接近的《论语》名句是？（"君子固穷，小人穷斯滥矣" / "温故而知新" / "学而时习之"）
10. 本章在《里仁》篇中的位置是？（第一章 / 第二章 / 终章）
