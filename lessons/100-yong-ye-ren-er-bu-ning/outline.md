# 第 100 课 · 雍也仁而不佞

《论语·公冶长》第五章

## 原文

> 或曰："雍也仁而不佞。"子曰："焉用佞？御人以口给，屡憎于人。不知其仁，焉用佞？"

### 字词疏解

| 字 | 音 | 释义 |
|---|---|---|
| 或 | huò | 有人。不定代词，表示旁人的议论 |
| 雍 | yōng | 冉雍，字仲弓，孔门德行科弟子，孔子许其"可使南面" |
| 佞 | nìng | 口齿伶俐、能言善辩。此处指口才，不作"奸佞"解 |
| 焉用 | yān yòng | 哪里用得着（反问） |
| 御 | yù | 抵挡、对付。此指用言语与人应对辩驳 |
| 口给 | kǒu jǐ | 给读 jǐ，言语敏捷、应对不穷 |
| 屡 | lǚ | 常常、屡次 |
| 憎 | zēng | 憎恶、讨人厌 |
| 不知其仁 | bù zhī qí rén | 不能断定他是否仁。孔子不轻易以"仁"许人 |

### 译文

有人说："冉雍这个人有仁德，可惜没有口才。"孔子说："哪里用得着口才呢？用伶牙俐齿去顶人、辩人，常常招人讨厌。我不知道他是不是仁——但哪里用得着口才呢？"

## 核心思想

**仁在心上，不在嘴上 · 口才不是筹码**

1. **"或曰"是旁人的话** —— 不是孔子的定评。世俗的算法是"德才兼备"，缺一头就打折。
2. **孔子不认这笔账** —— 人家惋惜"不佞"，孔子反问"焉用佞"：你惋惜的那件东西，根本不值得惋惜。
3. **"御人以口给，屡憎于人"** —— 拿口才去对付人，一次显本事，久了人人烦。赢了口，输了人。
4. **"不知其仁"是分寸** —— 孔子从不轻易许人以仁，连颜回也只说"三月不违仁"。他不替人下定论。
5. **两次"焉用佞"** —— 末句重复，是盖棺：这件事不必再辩了。

## 生活应用

- **说话**：别把谈话当比赛。非赢不可的人，最后都没人跟他说话。
- **看人**：先看他怎么做，再听他怎么说。
- **做事**：先把事做成，再讲给人听；反过来，就成了"口给"。
- **教孩子**：嘴笨不是缺点，心正才是根本。

## 关联章句

- 《论语·学而》"巧言令色，鲜矣仁" —— 孔子对"会说话"的一贯警惕。
- 《论语·里仁》"君子欲讷于言而敏于行" —— 慢说快做。
- 《论语·公冶长》"雍也可使南面" —— 冉雍的分量在德行，不在口舌。
- 《论语·颜渊》"仁者，其言也讱" —— 仁者说话迟钝，正与"佞"相反。

## 十道测验

1. "或曰"的"或"是什么意思？（有人 / 或者 / 或许）
2. "雍"指谁？（冉雍，字仲弓 / 孔子的儿子 / 鲁国国君）
3. "佞"在这里是什么意思？（奸邪谄媚 / 口齿伶俐、能言善辩 / 谄媚讨好）
4. "焉用佞"的"焉"是什么意思？（哪里、怎么，反问 / 于是 / 在那里）
5. "御人以口给"的"御"是什么意思？（驾车 / 抵挡、对付 / 抵御外敌）
6. "口给"的"给"读音和意思是？（gěi，给予 / jǐ，言语敏捷、应对不穷 / jǐ，供给）
7. "屡憎于人"是什么意思？（常常招人憎恶 / 憎恶别人 / 屡次被人夸奖）
8. 孔子对"雍也仁而不佞"的态度是？（认同，可惜冉雍口才差 / 不赞成把"不佞"当短处，反问"焉用佞" / 认为冉雍不仁）
9. "不知其仁"体现了孔子什么态度？（不轻易以"仁"许人，评人有分寸 / 认为冉雍不仁 / 不了解冉雍）
10. 本章在《公冶长》篇中是第几章？（第四章 / 第五章 / 第六章）
