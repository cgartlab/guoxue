# 第 76 课 · 我未见好仁者，恶不仁者

《论语·里仁》第六章（全篇 26 章）

## 原文

> 子曰："我未见好仁者，恶不仁者。好仁者，无以尚之；恶不仁者，其为仁矣，不使不仁者加乎其身。有能一日用其力于仁矣乎？我未见力不足者。盖有之矣，我未之见也。"

### 字词疏解

| 字 | 音 | 释义 |
|---|---|---|
| 好 | hào | 喜爱、真爱。动词读去声。真爱好，不是口头说说、不是一时兴起 |
| 恶 | wù | 憎恶、厌弃。动词读去声。真心厌弃，见不仁如怕烫手 |
| 尚 | shàng | 同"上"，超过、胜过。"无以尚之"：没有什么能超过它 |
| 为仁 | wéi rén | 践行仁德。"为"是做的意思，"为仁"即行仁，是动词 |
| 加 | jiā | 加到、沾染。"不使不仁者加乎其身"：不让不仁的东西沾到自己身上 |
| 一日 | yī rì | 哪怕一天。极言时间之短——门槛低到只有一天 |
| 盖 | gài | 大概、或许。疑而未定之辞，替"力不足"的说法留了余地 |
| 我未之见也 | wǒ wèi zhī jiàn yě | 宾语前置，即"我未见之也"——我没有见过这样的人 |

### 译文

孔子说："我没有见过真正爱好仁德的人，也没有见过真正憎恶不仁的人。爱好仁德的人，那是再好不过了（没有什么能超过它）；憎恶不仁的人，他践行仁德，只是不让不仁的东西沾到自己身上。有谁能哪怕用一天的力气放在仁上吗？我没有见过力量不够的。大概有吧——只是我没有见过。"

## 核心思想

**仁不难，难在肯用力**

1. **"好仁""恶不仁"，都是真功夫** —— 不是嘴上说仁，是心里真爱真爱憎。好仁到头，天下没有东西比它更高；恶不仁到头，不让一丝不仁沾身。孔子说"我未见"，是叹这样的人少——也是点醒：口头上的多，真用心的少。
2. **爱与憎，其实是一把锁的两面** —— 真爱好干净的，见不得脏；对不仁的憎恶，正是爱仁的另一面。一是往里拉（好仁），一是往外推（恶不仁），成色一样，方向不同。
3. **仁不在远，就在肯不肯用力** —— 孔子不说"仁太难"，他把门槛降到"一天"：哪怕用一天的力气呢？肯迈这一步，就进了门。
4. **力不会不足，心常会不足** —— "我未见力不足者"是千古判语。做不到的从来不是力气，是决心。朱子："为仁在己，欲之则是。"仁这事不靠别人、不靠运气，全在自己肯不肯。
5. **盖有之矣，我未之见也** —— 孔子留了余地又不说死：或许真有力不足的，只是我没见过。温和的存疑，严正的鞭策——话说得客气，判断一点没松。

## 生活应用

- **立志**：想学一样东西、改一个毛病，别先问"我能不能坚持"，先做一天试试。孔子的门槛就是一天。
- **自查**：每次说"我做不到"，先分清是"力不足"还是"心不足"。真正力不足的很少，多半是心先松了。
- **待人**：不要求别人一步成圣。谁肯用力一天，就给谁肯定——拉一把，比骂一顿管用。
- **惜身**：坏习惯、坏念头，"不使加乎其身"——一次都不让它沾上，沾上第一次就有第二次。

## 关联章句

- 《论语·里仁》"富与贵，是人之所欲也……造次必于是，颠沛必于是" —— 上一章（第五章）讲守仁，本章讲向仁用力。
- 《论语·里仁》"人之过也，各于其党。观过，斯知仁矣" —— 下一章（第七章，第 75 课）讲怎么看清别人；本章讲自己怎么用力。
- 《论语·述而》"仁远乎哉？我欲仁，斯仁至矣" —— 与本章同一口气：仁不在远，全在自己。
- 《论语·雍也》"回也，其心三月不违仁" —— 颜回正是"好仁者"的样子，三月不违，日日用力。
- 朱熹《集注》"为仁在己，欲之则是，而志之所至，气亦至焉" —— 点破"力不足"是托词。
- 《孟子·梁惠王上》"不为者与不能者之形，何以异" —— 不能与不为，孟子专门分过：挟太山以超北海，不能也；为长者折枝，不为也。

## 十道测验

1. "我未见好仁者"的"好"怎么读、什么意思？（hào，喜爱、真爱 / hǎo，好坏的好 / hào，爱好游玩）
2. "无以尚之"的"尚"是什么意思？（同"上"，超过、胜过 / 尚且 / 和尚）
3. "恶不仁者，其为仁矣"的"为仁"是什么意思？（践行仁德 / 为了仁这个目的 / 成为仁人）
4. "不使不仁者加乎其身"的"加"怎么讲？（沾染、侵扰 / 加法的加 / 加倍）
5. 孔子问"有能一日用其力于仁矣乎"，他想说的是？（仁不难，难在肯用力 / 仁太费力，做不成 / 一天的时间不够用）
6. "我未见力不足者"的意思是？（没见过真正力气不够的 / 没见过力气大的人 / 大家的力气都不够）
7. "盖有之矣，我未之见也"表现了孔子怎样的态度？（留了余地，但判断没有松 / 完全肯定有力不足的人 / 完全否认有力不足的人）
8. 本章在《里仁》篇中的位置是？（第六章 / 第五章 / 第七章）
9. "我未之见也"是什么句式？（宾语前置，即"我未见之" / 省略主语的省略句 / 反问句）
10. 本章与《述而》哪一句意思最接近？（"我欲仁，斯仁至矣" / "三人行，必有我师焉" / "学而时习之，不亦说乎"）
