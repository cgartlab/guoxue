# 第 101 课 · 吾斯之未能信

《论语·公冶长》第六章

## 原文

> 子使漆雕开仕。对曰："吾斯之未能信。"子说。

### 字词疏解

| 字 | 音 | 释义 |
|---|---|---|
| 使 | shǐ | 让、叫。此处是老师的举荐与提议，不是"派" |
| 仕 | shì | 出仕、做官 |
| 漆雕开 | qī diāo kāi | 姓"漆雕"，名"开"。孔门弟子，少孔子十一岁，以德行见长，习《尚书》 |
| 对 | duì | 回答。多用于下对上，故答老师曰"对" |
| 斯 | sī | 这、这个。代指出仕这件事，一说指为政之理 |
| 之 | zhī | 结构助词，宾语前置的标志。"吾斯之未能信"即"吾未能信斯" |
| 信 | xìn | 真知、确信，心里毫无疑惑。非空口"信心" |
| 说 | yuè | 通"悦"，高兴。读 yuè，不读 shuō |

### 译文

孔子让漆雕开去做官。他回答说："我对这件事还没有真切的把握。"孔子听了很高兴。

## 核心思想

**心里没底 · 就别急着上台**

1. **"使"是器重，也是试探** —— 老师举荐学生出仕，是看他学成了；同时也在问一句：你自己觉得行不行。
2. **"斯"是那副担子** —— 指做官这件事，一说指为政之理。两说都通，落点相同：这个担子，我不敢说自己懂了。
3. **"信"是对自己的诚实** —— 不是嘴上说"我能行"，是心里确确实实明白、没有一丝疑惑。
4. **"未能"不是"不能"** —— 留了余地：现在还不够，不是一辈子不行。既不逞强，也不自弃。
5. **一个"说"字，把整章翻过来** —— 学生辞了官，老师反倒欢喜。孔子要的不是听话的学生，是有判断的学生。

## 生活应用

- **机会**：递到手里的，不一定都要接。先问一句"这事我心里有底吗"。
- **学习**：把"我懂了"改成"我能讲一遍"。讲不通，就是还没懂。
- **做事**：没底就上手，是拿人家的事练手。承认没底，是长本事的开始。
- **教孩子**：敢说"我还没学会"，是本事；不敢说，才是麻烦。

## 关联章句

- 《论语·里仁》"不患无位，患所以立" —— 不怕没位置，怕没有立得住的东西。
- 《论语·先进》"子路使子羔为费宰。子曰：贼夫人之子" —— 同样是推人做官，子羔被推着去，孔子骂；漆雕开推回来，孔子悦。
- 《论语·泰伯》"三年学，不至于谷，不易得也" —— 读三年书不惦记俸禄，难得。漆雕开正是这种人。
- 《论语·子张》"学而优则仕" —— 孔子一派确实主张出仕，但前提是"优"。

## 十道测验

1. "子使漆雕开仕"的"仕"是什么意思？（出仕、做官 / 读书 / 出使）
2. "漆雕"是什么？（一种雕刻手艺 / 复姓，漆雕开姓漆雕名开 / 地名）
3. "对曰"的"对"是什么意思？（反对 / 跟着说 / 回答，下对上）
4. "吾斯之未能信"的"斯"指什么？（这个人 / 这、这个，指出仕这件事或为政之理 / 于是）
5. "吾斯之未能信"的正常语序是？（吾未能信斯 / 斯未能信吾 / 吾信斯之未能）
6. "信"在本章中的意思最接近？（书信、信件 / 相信别人 / 真知，心里确确实实有把握）
7. "子说"的"说"读音和意思是？（shuō，说话 / yuè，通"悦"，高兴 / shuì，劝说）
8. 学生推辞不做官，孔子为什么反而高兴？（因为不想让学生离开 / 因为本来就不赞成做官 / 因为看出学生诚实、知道自己斤两）
9. "未能"两个字说明什么？（现在还不够，不是一辈子不行 / 永远做不到 / 心里不想去做）
10. 本章在《公冶长》篇中是第几章？（第四章 / 第五章 / 第六章）
