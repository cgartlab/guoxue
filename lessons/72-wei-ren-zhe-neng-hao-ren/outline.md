# 第 72 课 · 唯仁者能好人，能恶人

《论语·里仁》第三章（全篇 26 章）

## 原文

> 子曰："唯仁者能好人，能恶人。"

### 字词疏解

| 字 | 音 | 释义 |
|---|---|---|
| 唯 | wéi | 只、唯独。孔子用此字立标准，不留余地 |
| 仁者 | rén zhě | 有仁德的人，心里有是非，待人有准头 |
| 能 | néng | 能够做到，而且做得恰当。非"有权力""有本事" |
| 好 | hào | 喜爱、赞许，动词。非"好坏"的 hǎo |
| 恶 | wù | 厌恶、憎恶，动词。非"善恶"的 è |
| 能好人 | néng hào rén | 能恰当地喜爱人：喜欢的是他身上的"好"，非他能给的"利" |
| 能恶人 | néng wù rén | 能恰当地厌恶人：恶其行，不恶其为人 |

### 译文

孔子说："只有有仁德的人，才能够恰当地喜爱人，也才能够恰当地厌恶人。"

## 核心思想

**好恶得当，才是真修养**

1. **好恶人人有，得当最难得** —— 喜欢与厌恶每天都在发生，恰恰最容易偏。
2. **能好人** —— 见人之善而真心喜之，不为私利。会做人是术，能好人是德。
3. **能恶人** —— 恶其不仁，不泄私愤。恶有对象、有分寸、有公心；该恶不恶即"乡愿，德之贼也"。
4. **无私心，才有准头** —— 有求则抬价，有怨则贬价；无求无怨，心平眼清。
5. **好恶是仁最日常的出口** —— 仁不在远方，就在每天夸谁、嫌谁里。

## 生活应用

- **交友**：喜欢他，也要在他将犯错时提醒，一味叫好不叫朋友。
- **生气**：厌恶他，仍能说出他一处优点——说得出来，心就没偏。
- **说话**：说事不判人，说这一件错事，别把一辈子的账都算上。
- **学习**：好而知其短，恶而知其长，心平眼清才学得进去。

## 关联章句

- 《论语·颜渊》"爱之欲其生，恶之欲其死" —— 好恶之偏的典型。
- 《大学》"好而知其恶，恶而知其美者，天下鲜矣" —— 与本章相发。
- 《论语·阳货》"乡愿，德之贼也" —— 该恶不恶之病。
- 朱熹《集注》"惟仁者，无私心，故能好恶皆当於理" —— 本章的经典注脚。

## 十道测验

1. 本章的说话人是谁？（孔子 / 有子 / 曾子）
2. "唯"是什么意思？（只、唯独 / 思考 / 应答）
3. "好"的读音和意思？（hǎo 善良 / hào 喜爱 / hào 喜好之物）
4. "恶"的读音和意思？（è 罪恶 / wū 哪里 / wù 厌恶）
5. "能"最恰当的理解？（有权力 / 做得到且做得恰当 / 有本事）
6. 为什么只有仁者能？（地位高 / 无私心故好恶合理 / 性格温和）
7. 仁者的"恶人"恶的是什么？（不仁之事，不泄私愤 / 意见不同者 / 地位低者）
8. 孔子批评"该恶不恶"用了哪句？（巧言令色 / 乡愿，德之贼也 / 讷于言敏于行）
9. 与本章最接近的一句？（好而知其恶，恶而知其美 / 学而时习之 / 温故而知新）
10. 本章在《里仁》篇的位置？（第一章 / 第三章 / 终章）
