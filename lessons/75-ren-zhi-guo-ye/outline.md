# 第 75 课 · 人之过也，各于其党

《论语·里仁》第六章（全篇 26 章）

## 原文

> 子曰："人之过也，各于其党。观过，斯知仁矣。"

### 字词疏解

| 字 | 音 | 释义 |
|---|---|---|
| 过 | guò | 过失、过错。本章专指无心之失，与明知故犯的"恶"分得很清 |
| 党 | dǎng | 类、类别。《孔安国注》："党，类也。"非政党，非"结党营私"之党 |
| 各于其党 | gè yú qí dǎng | 各随他那一类。"于"是随、依。什么人犯什么错，有规律可循 |
| 观 | guān | 看、细察。非冷眼旁观，是带着心看。同《学而》"观其志"之"观" |
| 斯 | sī | 就、于是。"斯知"即"就知道" |
| 仁 | rén | 仁德；一说通"人"。"知仁"即"知此人仁不仁"，亦可解作"知此人" |

### 译文

孔子说："人的过失，各随他那一类（性情不同，犯的错也不同）。看一个人犯的是什么错，就知道他仁不仁了。"

## 核心思想

**一把看人的尺子**

1. **过有类别，不是乱出的** —— "党"是类，不是派。人的性情有偏处，偏在哪边，错就往哪边出。急躁的错在催，心软的错在纵，得势的错在骄。
2. **看错，比看对更准** —— 长处能装，短处装不了。施舍、客气、说好话都能做给人看；急了累了、没防备时露出的才是本性。做对的千人一面，做错的人人不同。
3. **厚与薄，是分水岭** —— 程子曰："君子常失于厚，小人常失于薄；君子过于爱，小人过于忍。"两人都错，错的方向不一样。错在厚的一边，心是正的；错在薄的一边，心已经偏了。
4. **观过是知人，不是定罪** —— 孔子教"知"，不教"断"。看自己的过，找出偏处好改；看别人的过，分厚薄好相处。尺子别当刀使。
5. **在篇中的位置** —— 第五章讲自己怎么守（富贵不搬心、贫贱不走歪、造次颠沛脚不挪），本章转过身来讲怎么看清别人。一守一看，一内一外。

## 生活应用

- **看人**：别只看他做对的事。看他一次把事办砸、一次话说重、一次被惹急——错在厚处可交，错在薄处心里要有数。
- **看己**：把记得起来的几次错写下来，找共同点：都因急、因软、因怕、因贪？找到共同点，就找到了自己偏的那一处。
- **待人**：同为过失，方向不同，处置也该不同。心太软误事的，给个规矩；心太硬伤人的，留一分距离。
- **分寸**：观过是为了看懂人、好好相处，不是攒材料给人定罪。尺子用来量长短，刀才用来切东西。

## 关联章句

- 《论语·里仁》"富与贵，是人之所欲也……造次必于是，颠沛必于是" —— 上一章讲自己怎么守，本章讲怎么看清别人。同一理：真东西都在人顾不上修饰时露出来。
- 《论语·为政》"视其所以，观其所由，察其所安，人焉廋哉" —— 同是识人法，彼观其所由，此观其所过。
- 《论语·卫灵公》"君子求诸己，小人求诸人" —— 观过先观己，是这条尺子的正用。
- 程子（朱熹《集注》引）"君子常失于厚，小人常失于薄；君子过于爱，小人过于忍" —— 本章经典注脚。
- 朱熹《集注》"于此观之，则人之仁不仁可知矣" —— 点出"观过"的落处。
- 《孟子·公孙丑下》"君子之过也，如日月之食焉：过也，人皆见之；更也，人皆仰之" —— 有过不怕人看，改了还是亮的。

## 十道测验

1. 本章的说话人是谁？（孔子 / 曾子 / 子夏）
2. "各于其党"的"党"是什么意思？（类、类别 / 政党派别 / 乡党老乡）
3. "观过"的"观"怎么讲？（看、细察 / 观赏游览 / 道观庙宇）
4. "斯知仁矣"的"斯"是什么意思？（就、于是 / 此、这个 / 斯文文雅）
5. 为什么"观过"能看出一个人？（过失无心流露装不出来 / 过失多说明经验多 / 过失是别人评价的比较客观）
6. "君子常失于厚，小人常失于薄"的意思是？（君子过在心太厚，小人过在心太薄 / 君子因厚道失败 / 君子失在钱财）
7. 本章"过"与"恶"的分界？（过是无心之失，恶是明知故犯 / 过是小事恶是大事 / 过是自己的恶是别人的）
8. 本章在《里仁》篇的位置？（第六章 / 第五章 / 第一章）
9. "仁"通"人"这一读法怎么理解？（知仁即知人 / 此读法是错的 / 知道别人怎么看他）
10. 与第 74 课"造次必于是，颠沛必于是"的共同点？（都在人没防备时看真本色 / 都在讲求富贵 / 都在讲读书方法）
