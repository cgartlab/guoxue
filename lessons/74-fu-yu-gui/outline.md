# 第 74 课 · 富与贵，是人之所欲也

《论语·里仁》第五章（全篇 26 章）

## 原文

> 子曰："富与贵，是人之所欲也；不以其道得之，不处也。贫与贱，是人之所恶也；不以其道得之，不去也。君子去仁，恶乎成名？君子无终食之间违仁，造次必于是，颠沛必于是。"

### 字词疏解

| 字 | 音 | 释义 |
|---|---|---|
| 处 | chǔ | 居、安住，指接受下来、在那儿安身。非 chù（地方） |
| 恶（人之所恶） | wù | 厌恶、厌弃 |
| 恶（恶乎成名） | wū | 何、怎么。"恶乎"即"于何""凭什么" |
| 去 | qù | 离开、躲开、摆脱。"不去"即不躲开、不摆脱 |
| 终食之间 | zhōng shí zhī jiān | 吃完一顿饭的工夫，形容时间极短 |
| 违 | wéi | 离开、背离 |
| 造次 | zào cì | 仓促、匆忙，事到临头之时 |
| 颠沛 | diān pèi | 跌倒、困顿、流离失所 |
| 是 | shì | 此，代指"仁"。"必于是"即一定守在这里 |
| 得之（贫贱句） | dé zhī | 承上文而对文成辞，主流说当"去/摆脱"讲；朱子一路解为"不以道而得贫贱" |

### 译文

孔子说："财富和地位，是人人都想要的；若不用正当的方法得到，就不接受。贫穷和低贱，是人人都厌弃的；若不用正当的方法摆脱，就不摆脱。君子离开了仁，凭什么成就名声呢？君子在一顿饭的工夫里都不违背仁，仓促匆忙时是这样，困顿流离时也是这样。"

## 核心思想

**四道关，一道都不许漏**

1. **富贵可欲，不可苟得** —— 孔子先说"是人之所欲也"，不唱高调。反对的不是富贵，是"不以其道"。"不处"是心不搬家。
2. **贫贱可厌，不可苟去** —— "得之"此处当"去"讲：不歪着摆脱。朱子一路则说贫贱也有自招的，安心受之。两说同一落脚：不许走歪门。
3. **仁是君子的实名，不是招牌** —— 去仁不是做错一件事，是把"我是谁"丢了。朱子："无君子之实矣，何所成其名乎？"
4. **仁要守到一顿饭、一步急、一次难** —— 终食之间是一顿饭，造次是仓促，颠沛是困顿。平日守不算数，急难时守得住才算。
5. **在篇中的位置** —— 第四章讲"志"是根，本章讲这志怎么落地。一内一外，一志一行。

## 生活应用

- **钱上**：先问"拿得心安吗"，再问"拿得到吗"；过不去，就不处。
- **难处**：急事可以求人，不可以骗人；可以少赚，不可以少给。
- **自处**：别把身份挂在位子、票子、房子上，挂在自己认的那条道上。
- **日常**：守仁不在大事，在吃饭、赶时间、堵车这些碎片里。

## 关联章句

- 《论语·述而》"富而可求也，虽执鞭之士，吾亦为之" —— 孔子不反对求富贵，反对不以其道。
- 《论语·里仁》"苟志于仁矣，无恶也" —— 上一章立志是根，本章是这志的落地检验。
- 《论语·里仁》"君子喻于义，小人喻于利" —— 同篇延伸，义利之辨。
- 朱熹《集注》"若贪富贵而厌贫贱，则是自离其仁，而无君子之实矣，何所成其名乎？" —— 本章经典注脚。
- 俞樾《群经平议》、杨伯峻《论语译注》 —— "贫与贱……得之"之"得"当"去"讲。

## 十道测验

1. 本章的说话人是谁？（孔子 / 有子 / 曾子）
2. "不处也"的"处"读音与意思？（chǔ 安居接受 / chù 地方 / chǔ 处罚）
3. "人之所恶也"的"恶"读音？（wù 厌恶 / è 恶事 / wū 怎么）
4. "恶乎成名"的"恶"读音与意思？（wū 何怎么 / wù 厌恶 / è 凶恶）
5. "贫与贱……得之"的"得之"主流解释？（当"去/摆脱"讲 / 得贫贱之名 / 得摆脱的机会）
6. "终食之间"是什么意思？（一顿饭的工夫 / 一生一世 / 一整天）
7. "造次"与"颠沛"分别指？（仓促匆忙 / 困顿流离）
8. 本章在《里仁》篇的位置？（第一章 / 第五章 / 终章）
9. "君子去仁，恶乎成名"的正确理解？（名本于仁，去仁则无其实 / 应追求名声 / 离仁更易出名）
10. 与第四章"苟志于仁矣"的关系？（四章讲根，本章讲落地 / 无关 / 四章讲富贵）
